# Resume and invalidation

Resume requires a prior successful compatible record plus matching canonical configuration digest, input/output checksums, executable/version/mode, and container identity. Patient FASTA changes invalidate assembly-dependent callers, normalization, packaging, and validation. Mini-BAM changes invalidate read callers and downstream normalization/package stages. Locus/resource changes invalidate consumers and downstream work. A caller executable change invalidates that caller and downstream work. Native corruption invalidates normalization; unified-evidence corruption invalidates packaging; package corruption invalidates validation. Package option changes invalidate Stage 09. Stable absence of an optional caller remains explicit and never fabricates evidence.
