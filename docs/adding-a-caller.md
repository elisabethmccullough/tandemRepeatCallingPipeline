# Adding a caller safely

1. Define stable caller identity. 2. Define `analysis_source`. 3. Define assignment policy (read evidence stays unassigned unless directly justified). 4. Add discovery. 5. Add version classification. 6. Isolate a provisional adapter. 7. Emit a typed argv command plan without a shell. 8. Register immutable native outputs and checksums. 9. Add a lossless parser. 10. Add the normalized schema without implying equivalence. 11. Retain run metadata. 12. Add a clearly labelled fake tool. 13. Add valid and failing fixtures. 14. Version the GUI contract. 15. Test missing/unsupported/failure/resume cases. 16. Add an unfilled real-tool verification template and controlled review.

Shared normalized fields support display and provenance; they do not mean two callers measure equivalent quantities. Never create consensus, preference, clinical classification, or unsupported sequence assignment.
